# Personal Finance & Investment Tracker

Personal-use Flutter application for expense, credit-card, receipt, and future investment tracking.

## AI-assisted development

This repository includes a durable AI-context system:
- `.github/copilot-instructions.md`
- `docs/`
- `.vscode/mcp.json`

See `docs/README.md` for the documentation map.

## MCP servers
- Filesystem — current local repository context
- GitHub — repository/issues/PR context
- Context7 — current library/framework documentation

## Important
Do not commit secrets, API keys, Firebase admin credentials, or personal financial data.
